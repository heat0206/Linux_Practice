# Basic Shell Scripting Commands

1. **list command (ls)**:

**Purpose**: Lists the files and directories in the current working directory.

```bash
ls [options] [directory]
```

### Common Options

|Command|Description|
|-------|-----------|
|ls|List Files|
|ls -a| Show hidden files|
|ls -l| Long Format |
|ls -t| Sort by Time |
|ls -r| Reverse Order |
