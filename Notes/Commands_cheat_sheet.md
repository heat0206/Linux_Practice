# Commands For Shell Scripting

1. **ls** : Lists all the files in the current working directory.
2. **ls -a** : Prints ALL the files in CWD , even the hidden files (ones whose name start with '.'(like .filename))
3. **ls -t**: Sort By Modification Time.
4. **ls -r**: Reverse the order of sorting.
3. **pwd**: Prints the current working directory.
